# ✈️ AeroVista — Aeroplane Tours & Travels Website

AeroVista is a modern, responsive travel website built using **React, Vite, and CSS**. It provides an engaging interface for exploring destinations, discovering holiday packages, searching for flights, and starting a travel booking.

The project features a premium airline-inspired design, smooth scrolling, animated sections, and a cinematic preloader.

## ✨ Features

- **Animated Preloader** — Cinematic travel-themed intro with an airplane animation and progress indicator.
- **Responsive Navbar** — Navigation to the main website sections.
- **Hero Section** — Attractive travel visuals and booking call-to-action.
- **Flight Search** — Search flights by entering travel details.
- **Popular Destinations** — Explore destinations with search, category filters, and sorting.
- **Holiday Packages** — Browse travel packages with prices and package details.
- **Travel Services** — Discover flight booking, accommodation, itinerary planning, and other services.
- **About Section** — Information about AeroVista and its travel-planning concept.
- **Contact Form** — Form validation and a submission confirmation interface.
- **Booking Flow** — Select from sample flights, review passenger details, and view a booking confirmation.
- **Smooth Scrolling** — Smooth navigation between sections.
- **Scroll Animations** — Sections reveal as the user scrolls.
- **Responsive Design** — Layout adapts to desktop, tablet, and mobile screens.
